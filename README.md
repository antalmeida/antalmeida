  ## 📚 Recursos educativos gratuitos

Uma seleção de ferramentas, tutoriais e atividades para aprender e ensinar.

### 💻 Programação e desenvolvimento web

| Recurso | Como utilizar |
|---|---|
| [Scratch](https://scratch.mit.edu/) | Criar jogos, animações e histórias interativas com programação por blocos. |
| [MDN Web Docs — Aprender desenvolvimento web](https://developer.mozilla.org/en-US/docs/Learn_web_development) | Construir uma primeira página e praticar HTML, CSS e JavaScript. Conteúdos em inglês. |
| [GitHub Skills — Introduction to GitHub](https://github.com/skills/introduction-to-github) | Praticar a criação de um ramo, de um commit e de um pull request num exercício guiado. Em inglês. |

### 🤖 Robótica e eletrónica

| Recurso | Como utilizar |
|---|---|
| [Microsoft MakeCode para micro:bit](https://makecode.microbit.org/) | Programar jogos, contadores ou sensores e testar o programa no simulador, mesmo sem uma placa. |
| [Tinkercad Circuits](https://www.tinkercad.com/circuits) | Montar e simular circuitos com LEDs, botões e Arduino antes da montagem física. |
| [Arduino — Exemplos oficiais](https://docs.arduino.cc/built-in-examples/) | Experimentar programas básicos, como piscar um LED, ler um botão ou medir um sinal analógico. Em inglês. |

### 📊 Matemática, ciências e análise de dados

| Recurso | Como utilizar |
|---|---|
| [GeoGebra](https://www.geogebra.org/) | Explorar funções, interseções de retas e construções geométricas com seletores. |
| [PhET — Simulações interativas](https://phet.colorado.edu/pt/) | Investigar conceitos de física, química e matemática através de simulações. Inclui recursos em português. |
| [PORDATA](https://www.pordata.pt/) | Comparar indicadores de Portugal, dos municípios e da Europa e criar gráficos com dados reais. |

### 🛡️ Cidadania digital, cultura e media

| Recurso | Como utilizar |
|---|---|
| [SeguraNet — Direção-Geral da Educação](https://www.erte.dge.mec.pt/seguranet) | Trabalhar a segurança online e a cidadania digital com materiais dirigidos à comunidade escolar. |
| [Creative Commons — Guia de licenças](https://creativecommons.org/cc-licenses/) | Identificar em que condições se pode reutilizar, adaptar ou partilhar uma obra. |
| [RTP Ensina](https://ensina.rtp.pt/) | Usar vídeos e outros conteúdos em português para introduzir temas e lançar debates em aula. |
